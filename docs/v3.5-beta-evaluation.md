# v3.5.0-beta.1：测试方法、结果与成本

核对日期：2026-10-21。本文公开维护者已有实验的汇总，不构成独立第三方认证。本次发布没有新增模型测试。

## 发布了什么

发布的是提示词优化器 v3.5 候选。它在本机 v3.4 基础上增加两处要求：合并多轮授权，以及保留执行任务的完成条件。其他提示词规则和方法参考保持原样。

发布入口 `SKILL.md` 与实测候选逐字一致，其 SHA-256 内容校验值为：

```text
ee8b4c92c17071f3adedab86ef8fbb036484a1c92034b2365e280174fe8d79c2
```

`references/methods.md` 的内容校验值为：

```text
d5d1a9484264f078067cbdbcff2dc427bb514bf2f786083f5534d9d95d3353db
```

公开仓库旧版的文件头比本机旧版多了许可、版本等发布信息。本测试版直接保留实测文件，因此与公开 v3.4.0 的差异还包括文件头；MIT 许可由仓库的 `LICENSE` 保留。版本标签、说明和宿主显示名标明测试版。

## 怎么比较

比较五种输入：本机 v3.4、v3.5 候选、Prompt Optimizer 的指定模板、OpenAI 的指定元提示词，以及未经优化的原始任务。

- 开发阶段：6 个任务 × 5 种输入 × 1 个执行模型，共 30 次首次执行。
- 确认阶段：6 个新任务 × 5 种输入 × 2 个执行模型，共 60 次首次执行。
- 优化稿由同一个 `gpt-6.1-sol` 模型生成，使用 medium 推理设置。开发阶段由 `gpt-6-luna` 执行；确认阶段由 `gpt-6-luna` 和 `gpt-6.1-sol` 执行。
- 共 12 个不同任务实例。确认阶段的同一份优化稿交给两个执行模型，不重复生成。每个任务、每种输入、每个执行模型只保留首次结果，没有用重试择优。
- 判定依据为预先冻结的任务要求、实际输出与模拟工具回执，不以模型自称完成为准。文件操作和发布发生在本地模拟环境，没有执行外部业务发布。
- 确认任务由独立设计者准备，设计时未读取开发阶段输出，但看过开发题目和早期汇总进度，因此不称为完全盲测。

## 观察结果

| 输入 | 开发：gpt-6-luna | 确认：gpt-6-luna | 确认：gpt-6.1-sol |
|---|---:|---:|---:|
| v3.4 | 5/6 | 6/6 | 6/6 |
| v3.5 | 6/6 | 6/6 | 6/6 |
| Prompt Optimizer 指定模板 | 6/6 | 6/6 | 6/6 |
| OpenAI 指定元提示词 | 6/6 | 6/6 | 6/6 |
| 原始任务 | 6/6 | 6/6 | 6/6 |

90 次首次执行中，89 次通过、1 次失败、0 次无法确认。唯一失败出现在开发阶段的 v3.4 输入：模型把未经核实的供应商自述数量写成了已完成数量，正确结果应保留未知。

v3.5、两个模板和原始任务各有 18 次通过观察。这不等于 18 个独立任务，也不能从 v3.4 的单次失败断言 v3.5 稳定更优。控制器后续补做的操作没有计入以上成绩。

## 用量与代价

以下 token 是模型记录的文本计量单位，不是费用金额。统计包含每个任务的一次优化，以及后续执行；确认阶段复用的优化稿只计一次。

| 输入 | 优化与执行合计 token |
|---|---:|
| v3.4 | 122,485 |
| v3.5 | 126,890 |
| Prompt Optimizer 指定模板 | 49,313 |
| OpenAI 指定元提示词 | 61,960 |
| 原始任务 | 31,203 |

共 138 次命令行会话、228 次实际模型响应请求，合计 391,851 token：输入 363,743，输出 28,108。缓存输入 45,056 已包含在输入总量中，不能再相加。统计不含宿主整理与审查用量，也不是账单。

在这组实验中，v3.5 用量约为 Prompt Optimizer 指定模板的 2.57 倍。简单任务可以直接提问；现有结果没有证明优化的额外用量带来了稳定收益。

## 结论能支持到哪里

这些结果支持把候选开放为测试版，供真实使用反馈。样本少、任务类型有限，同一条件没有多次抽样；不能宣称统计上等效、稳定不劣于其他工具、普遍更好，或已经修复执行模型的漏项。

提示词中的要求不能代替执行器的实际校验。本次发布没有把内部模拟执行器、结束前检查或恢复控制器做成生产功能。

第三方模板原文没有收入本发布包；它们的许可仍以各自来源为准。候选正文没有复制这两份模板。
