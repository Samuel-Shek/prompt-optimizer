# 使用示例

以下是为说明用法编写的虚构示例，不是新增测试结果。把材料交给优化器，它返回可交给执行模型的提示词；是否执行仍由原来的任务与授权决定。

## 把多轮修改整理成当前要求

```text
使用 $prompt-optimizer，把以下对话整理成一份执行提示词。
最初：发布 draft-a.md 和 draft-b.md，发布后分别重新读取确认。
随后：暂停全部发布。
现在：只恢复 draft-a.md 的一次发布，成功后重新读取一次；draft-b.md 继续暂停。
不要执行这些动作，只返回提示词。
```

应保留的意思：当前只发布 `draft-a.md` 一次，成功后重新读取一次。`draft-b.md` 仍禁止发布，过去读过文件不抵扣此次重新读取。

## 只审阅，不重写

```text
使用 $prompt-optimizer。先评价，别改：
“读取附件并做出结论；如果信息不足，就假设所有步骤都已完成。”
只指出会影响可靠执行的问题。
```

这里要求的是审阅结果。优化器不应直接执行附件任务，也不应自行附一份完整重写稿。

## 保留原任务的限制

```text
使用 $prompt-optimizer，帮我整理一条研究提示词。
只用公开资料比较三种笔记工具，注明来源与日期。
不要注册账号、购买服务或替我作最终选择。
```

生成的研究要求应保留资料范围、来源日期和三个禁止项。需要什么工具、能否联网，由实际宿主能力决定。
